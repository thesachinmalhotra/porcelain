# Security Policy

## Reporting a vulnerability

Please do not open a public GitHub issue for a suspected security vulnerability.

Use GitHub's private security advisory workflow:

https://github.com/thesachinmalhotra/porcelain/security/advisories/new

Include enough detail to reproduce and assess the issue, including affected versions or commits when known.

## Handling

Security reports should remain private while they are being investigated and remediated. Once a fix is available, the maintainers can coordinate disclosure and release notes as appropriate.

Please do not include real credentials, tokens, private keys, or other sensitive data in a report. Use redacted examples.

## Supported versions

There is currently no published long-term support matrix. Security fixes are expected to target the current development line unless a release explicitly states otherwise.
